# Задание агенту Codex — STAGE_03

**Репозиторий:** heroicrealm/CodexAgent
**Рабочая ветка:** STAGE_03 (НЕ main)
**Полное ТЗ:** docs/stages/stage03.md

Реализовать этап 3 «Очередь заданий и ручное подтверждение» строго по указанной спецификации.

1. Проанализировать текущие src/, tests/, README, docs/specification.md, SQLite Store.confirm/reset_confirmation и контракт GitHub polling этапа 2.
2. Добавить CLI queue/show/approve/reject, атомарные переходы и историю решений. Не вводить статус approved.
3. Реализовать безопасное подтверждение через GitHub Labels, включая проверку доверенного инициатора; запретить подтверждение только по метке pending.
4. Добавить конфиг name/color/description, init и init --update, read-only doctor, init_status/init_message/init_fingerprint и фильтрацию неинициализированных проектов во всех путях обработки.
5. Реализовать устойчивую синхронизацию индикаторных меток GitHub с SQLite и защиту от повторного применения команд.
6. Написать автоматические тесты по разделу критериев приёмки; сохранить совместимость этапов 1–2; обновить README и config.example.yaml.
7. Выполнить bash scripts/test.sh; зафиксировать изменения коммитом в STAGE_03 и предоставить отчёт: файлы, тесты, ограничения и риски.

**Не делать:** Codex executor, worktree, push/PR, merge, автоматическое выполнение заданий; не менять main. Если надёжная проверка инициатора GitHub-метки технически невозможна, не обходить требование: сообщить о блокере вместо небезопасной реализации.
