# Задание агенту — STAGE_02: GitHub Issues

Репозиторий: heroicrealm/CodexAgent. Рабочая ветка: **STAGE_02** (уже создана от main).
Полное утверждённое ТЗ: [docs/stages/stage02.md](../../docs/stages/stage02.md).
Общее ТЗ: docs/specification.md.

## Что сделать
1. Изучить фактический код этапа 1 и текущую схему конфигурации/SQLite, сохранить совместимость.
2. Реализовать gh api adapter: пагинация, фильтры ready/author/repository, исключение PR, нормализация.
3. Реализовать идемпотентную синхронизацию SQLite, фиксацию версии и истории изменений.
4. Реализовать вариант A: до подтверждения обновлять снимок; после подтверждения при изменении содержимого отзывать подтверждение. Не переписывать активный/завершённый исполняемый снимок.
5. Реализовать отзыв готовности при закрытии Issue/снятии ready-метки; неполный опрос не должен вызывать массовый отзыв.
6. Добавить обработку ошибок, ограниченные повторы, безопасные логи и тесты из раздела 9 ТЗ.
7. Обновить инструкции и предоставить воспроизводимый способ проверить polling вручную.

## Ограничения
Не запускать Codex и не реализовывать публикацию PR/изменение GitHub labels. Не использовать shell=True, не хранить секреты. Не хардкодить прикладные репозитории. Не выполнять merge в main.

## Готовность
Все тесты проходят; два проекта корректно опрашиваются; повторный запуск не создаёт дублей; изменение Issue после подтверждения сбрасывает подтверждение; сбои не теряют очередь. В итоговом комментарии перечислить файлы, команды тестов, результаты и известные ограничения.
