## Объём
- Команда `queue`: человекочитаемая таблица в единой Unicode-рамке; вертикальные разделители колонок, без горизонтальных разделителей строк; цветные статусы при поддержке TTY, NO_COLOR, отключение ANSI для JSON и перенаправления вывода.
- Команда `show <project> <issue>`: карточка в единой Unicode-рамке, четыре секции (проект/репозиторий; метаданные; полный текст Issue; диагностические сведения), три горизонтальных разделителя; перенос длинных строк без усечения body.
- Для обеих команд `--format json` сохраняет прежний машиночитаемый контракт.
- Форматирование выделено в `src/dispatcher/rendering.py`; тесты и README дополнены. Изменений workflow, scheduler, схемы SQLite и других команд не требуется.
