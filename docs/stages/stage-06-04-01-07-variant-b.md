# 6.4.1.7 — вариант Б заменён добровольным завершением

Последний раздел [ТЗ](stage-06-04-01-07-spec.md) отменяет обязательный cgroup backend,
принудительную emergency-остановку и production fail-closed gate. Служба исполняет
задания без delegation в WSL2 и Linux-контейнерах. Действующий контракт, ограничения
cleanup и ручная матрица находятся в [отчёте реализации](stage-06-04-01-07-implementation.md).

Cgroup v2/systemd/broker остаются возможным отдельным развитием. Для такой функции
потребуются удержание границы до первого fork, запрет произвольной миграции,
устойчивая identity attempt, restart recovery и подтверждение пустоты всей границы.
Сканирование /proc, cwd или исчезновение PGID не эквивалентны этому доказательству.
Будущая kernel-матрица: setsid/setpgid, orphan/reparent, leader exit, migration/fork
races, PID reuse, controller failure и параллельные attempts. Сейчас она не является
обязательной приёмкой и не представлена skipped tests как выполненная гарантия.

В текущем контракте процессы должны сохранять исходную группу Lifecycle.
Произвольно отделившиеся процессы могут остаться невыявленными. При известных живых
пользователях worktree, незавершённом process journal, неизвестном exit_code после
restart либо ошибке ownership cleanup сохраняет артефакты. Только административный
stop --force посылает сигналы; timeout и GitHub labels этого не делают.
