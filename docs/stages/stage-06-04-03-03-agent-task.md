# Задание Codex-агенту — 6.4.3.3

Работать в `heroicrealm/CodexAgent`, ветка `STAGE_06_04_03`. Не объединять PR автоматически.

## Цель

Реализовать только [ТЗ 6.4.3.3](stage-06-04-03-03-spec.md) на основе [принятого ТЗ 6.4.3](stage-06-04-03-spec.md) и [аудита 6.4.3.2](stage-06-04-03-02-audit.md).

## Порядок

1. Прочитать текущие миграции, transitions, sync, scheduler, GitHub Adapter, workspace, branch/PR ownership и существующие тесты.
2. Проверить реальный контракт GitHub Sub-issues API и права, зафиксировать ограничения; не предполагать, что endpoint или conditional update реализуют CAS, без доказательства.
3. Добавить миграцию 614 и юнит-тесты на неё. Исторический `VERSION=602` не менять.
4. Добавить строгий YAML parse `issue_type/run_codex`, новый state/label и CLI-отображение. Сохранить поведение обычных Issue.
5. Реализовать идемпотентную раннюю публикацию контейнерной ветки и durable recovery после сбоя между remote Git и SQLite.
6. Реализовать API непосредственных Sub-issues, выбор учитываемых детей, аккуратную правку `dispatcher.base_branch` и fail-closed при гонках.
7. Встроить подготовку контейнера в scheduler без вызова Codex и PR publisher для него.
8. Написать тесты на happy/error/crash/restart/parallel-poll и регрессию; выполнить `bash scripts/test.sh`, `git diff --check` и представить отчёт с командами/результатами.

## Ограничения

Не делать 6.4.3.4+ (merge checks, интеграционный Codex, manual issues, повторная интеграция). Не запускать/подтверждать/отменять детей. Никаких force-push, auto-merge, искусственных коммитов, удаления пользовательских веток или скрытого переписывания Issue. Удаление ready с ребёнка с открытым PR блокирует родителя по принятому правилу A (основная обработка следующего подэтапа; в 6.4.3.3 не делать автоматического unblock).

## Отчёт

Перечислить изменённые файлы, миграции, контракт GitHub API, доказательство идемпотентности, обнаруженные ограничения, точное число тестов, неисполненные сценарии и инструкции ручной проверки. Не считать подэтап принятым до решения пользователя.
