# Codex Dispatcher 2.5.2

Поставка Standalone для Ubuntu native и Ubuntu/WSL2 без клонирования репозитория: wheel, автономные install/uninstall-скрипты, шаблон YAML (схема 1), SHA-256.

Перед `run`, включая `--once`, проверяются схема конфигурации и доступность GitHub API. Если доступна новая стабильная версия, выводится ссылка. При недоступности API требуется ответ y в терминале; без терминала запуск отклоняется. Ошибка только Releases не блокирует работу.

Старый YAML без `config_schema_version: 1` требует ручного согласования с `config.new.yaml`. Совместимые обновления меняют только `dispatcher_version`, сохраняя настройки и комментарии. Версия установленного пакета определяется по metadata, независимо от YAML.

Установка сохраняет предыдущую генерацию venv для безопасности. Удалитель сохраняет конфигурацию, SQLite, workspace, worktrees и credentials. Service (systemd) и Docker остаются отдельными этапами. Жизненный цикл Issue/PR, scheduler и поведение при потере сети во время работы не изменены.

Инструкции: docs/standalone.md. Этот файл — подготовленные release notes, не свидетельство публикации релиза или прохождения ручной приемки.
