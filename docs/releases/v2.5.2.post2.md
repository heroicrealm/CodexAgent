# Codex Dispatcher 2.5.2.post2 — Standalone V2.5.2.2

- Постоянная команда `codex-dispatcher-install` доставляется и переключается с поколением venv; чужие пути защищены, при ошибке выполняется rollback.
- До изменения установки проверяется SHA-256 реальных байтов запущенного установщика по manifest последнего стабильного Release. API/manifest/digest/checksum failure и несовпадение приводят к отказу; пользователь вручную скачивает и проверяет новый файл. Самоизменения и автоматического запуска скачанного файла нет.
- `codex-dispatcher --version` читает metadata `codex-dispatcher-v2` без конфигурации и runtime.
- Удаление требует `Proceed with uninstall? [y/N]:`; только `y` разрешает удаление. Отмена n/Enter/EOF/Ctrl+C: код 0, non-TTY: ненулевой код. Locks и ownership сохраняются; пользовательские данные не удаляются.

Версия пакета `2.5.2.post2`, `config_schema_version=1`. Scheduler, Issue/PR, Service и Docker не меняются.

С 2.5.2.post1 необходимо **один раз вручную скачать** новый `install-standalone.sh` и `SHA256SUMS` из одного конкретного Release, проверить `sha256sum --check --ignore-missing SHA256SUMS`, запустить `sh install-standalone.sh`. Затем использовать `codex-dispatcher-install`. Подробности: [руководство](../standalone.md).

Подготовлено к ручной приемке WSL2. Тег и стабильный Release публикуются владельцем только после отдельного разрешения. До публикации latest нового скрипта SHA с прежним Release не совпадет; candidate проверяется через mock API.
