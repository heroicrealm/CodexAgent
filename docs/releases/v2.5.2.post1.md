# Codex Dispatcher 2.5.2.post1

Корректирующая поставка V2.5.2.1 Standalone. Python-пакет и dispatcher_version: `2.5.2.post1`; config_schema_version: `1`.

Установщик доставляет uninstall-standalone.sh из того же GitHub Release после проверки SHA-256. Команда `codex-dispatcher-uninstall` доступна через ~/.local/bin. Скрипт находится в принадлежащем установщику поколении venv и переключается вместе с пакетом; при сбое восстанавливается прежняя генерация и YAML. Чужая команда удаления сохраняется с отказом установки/удаления.

Удаление требует остановки диспетчера, удаляет собственные поколения, скрипты, ссылки и ownership-маркер, сохраняет конфигурацию, SQLite, workspace и credentials. Общий lock-файл остается для предотвращения гонок. Обработка Issue, scheduler, PR и формат конфигурации не менялись.

Для обновления 2.5.2 скачайте свежий install-standalone.sh и SHA256SUMS, проверьте контрольную сумму и запустите установщик после остановки runtime. Старый установщик 2.5.2 не доставляет команду удаления.

Инструкции: docs/standalone.md. Bundle подготовлен для приемки; тег и Release не опубликованы.
